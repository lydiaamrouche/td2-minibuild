# TD2 — Question 7

Oui, les deux coordonnées appartiennent à la même classe d’équivalence :
ce sont des coordonnées valides au format `groupe:artefact:version`.

La triangulation demande deux exemples pour éliminer la solution « Fake it »
de la question 5. Avec une seule entrée, une valeur constante suffit à faire
passer le test. Avec deux entrées différentes, le code doit réellement
extraire le groupe, l’artefact et la version de chaque chaîne.
